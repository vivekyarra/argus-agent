👁️

Ambient Observation

Captures and analyzes screen frames every 10 seconds using pixel-diff detection, sending only meaningful changes to reduce API calls.

🧠

Gemini Vision Analysis

Each frame is analyzed by Gemini 2.0 Flash multimodal AI, extracting app context, errors, URLs, and activity summaries in structured JSON.

💬

Context-Aware Responses

When you speak or type a command, ARGUS references its rolling observation window to give specific, contextual answers about what it saw.

🖱️

Action Execution

ARGUS can click UI elements, type text, and open URLs autonomously — with confidence thresholding to prevent accidental actions.

☁️

Google Cloud Storage

Screenshots and action logs are persisted to Google Cloud Storage for audit trails, replay analysis, and cross-session context.

🗄️

Cloud Firestore

Structured observation and action data is stored in Firestore for real-time querying, historical analysis, and session tracking.
